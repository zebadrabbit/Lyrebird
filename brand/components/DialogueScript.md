# DialogueScript

A multi-speaker script as Lyrebird reads it: a line starting with a saved voice's name switches speaker.

The consumer provides lines of text. Speaker names that match a saved voice are bold `speaker`; text is `ink` in `script`; sound tags use SoundTag. Put the script on `surface` with a `line` border and `radius-md`, padded `space-4`. Use real, plausible dialogue in examples; `Built-in:` is the model's own voice.
